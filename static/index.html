节点配置

配置保存在本机，保存后立即生效。

每个节点可选择密钥或密码登录。密钥登录使用本机私钥，加密私钥请先加入 ssh-agent。密码以明文保存在本机配置文件，界面仅显示是否已设置；编辑时留空保留已有密码，切换到密钥登录会清除已存密码。

监控节点

地址支持 IP、主机名及 SSH Host 别名。用户名、端口留空时使用本机 SSH 配置；密钥登录时节点私钥覆盖默认私钥，密码登录仅使用所填密码。两种方式均校验服务器指纹。
